Premium WordPress theme for sarkariresult.edu.pl — government jobs, results, admit cards, and exam updates.

== Description ==

Classic Sarkari Result portal layout with a premium crimson/navy design, custom footer, FAQs, state-wise jobs, RRB grid, and qualification filters.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme
2. Upload `sarkariresult-theme.zip`
3. Activate **Sarkari Result Premium**
4. Settings → Reading → set a static front page (or leave default; `front-page.php` will still load for the site front)
