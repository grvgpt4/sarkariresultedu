Lightweight SEO-first theme for Sarkari Result education portals. Compatible with Yoast SEO, GA4, and AdSense.

== Description ==

Production theme for sarkariresult.edu.pl. Safe to activate on existing content — does not alter posts, pages, categories, or SEO metadata.

== Installation ==

1. Upload the theme folder to `/wp-content/themes/sarkariresult-theme/`
2. Activate through Appearance → Themes
3. Set Primary menu under Appearance → Menus
4. Configure options under Appearance → Customize → Sarkari Result Theme
