# Sarkari Result Theme

Production-ready WordPress theme for https://sarkariresult.edu.pl/

## Theme location

`sarkariresult-theme/` — upload this folder to `wp-content/themes/` and activate.

## Documentation

- PDF guide: [`docs/Sarkari-Result-Theme-Guide.pdf`](docs/Sarkari-Result-Theme-Guide.pdf)
- WordPress readme: [`readme.txt`](readme.txt)

## Safety

- Does not modify existing posts, pages, categories, or slugs
- Does not alter Yoast SEO metadata or create duplicate schema/canonicals
- GA4 and AdSense load only once and skip when conflicting plugins are detected

See the PDF guide for install steps and Customizer options.
