# sarkariresultedu

WordPress theme repository for **Sarkari Result** (https://sarkariresult.edu.pl/).

## Contents

| Path | Description |
|------|-------------|
| `sarkariresult-theme/` | Production WordPress theme |

## Quick install

1. Copy `sarkariresult-theme` to `wp-content/themes/`
2. Activate in **Appearance → Themes**
3. Assign **Primary** menu and configure **Appearance → Customize → Sarkari Result Theme**
